# MLform identity

MLform belongs to [eshkra](https://eshkra.dev). The original mark is the maintainer-supplied graphite ribbon F around an orange orb, copied unchanged from `eshkra/src/assets/marks/mlform.png`. Its embedded provenance is preserved.

Use Mona Sans Variable for the brand, headings and prose. Set **ML** at weight 800, width 125%, and letter spacing -0.01em; set **form** lowercase at weight 300 and width 100%. Keep the wordmark on one line. The standard Mona Sans files include both weight and width axes; the weight-only files cannot reproduce the wide ML.

Use JetBrains Mono for code and technical labels, with contextual alternates disabled. The self-hosted Latin and Latin Extended subsets come from Fontsource 5.3.0; their SIL OFL licenses are in `fonts/`. The light/dark SVG wordmarks contain outlined glyphs from these same fonts so GitHub and npm do not need to load a font.

The product accent is orange `#ff6a1a`, over neutral graphite or white. Use darker orange for small text on white. Library themes remain consumer choices; these assets brand the project website, documentation and playground, not every form built with MLForm.

Keep `mlform` unchanged in package names, imports, commands and URLs. Use the styled MLform wordmark for product identity; use plain `MLForm` in prose and accessible descriptions when styling is unavailable.
